📖 Manual y reglas de Triqui

El objetivo es conseguir tres símbolos iguales en línea . La línea puede ser horizontal, vertical o diagonal.

  • 1 vs 1: dos jugadores comparten la misma pantalla. X empieza y después juega O.
  • vs PC: el jugador utiliza X y empieza primero. La computadora utiliza O.

  • Fácil: la computadora elige una casilla vacía al azar.
  • Normal: primero intenta bloquear una victoria inmediata del jugador. Si no existe peligro, juega al azar.
  • Difícil: utiliza el algoritmo Minimax para no perder.

Cuando alguien gana, su punto se suma al marcador.

Si las nueve casillas quedan ocupadas sin ganador, se suma un empate.

Después de terminar una ronda, el tablero queda bloqueado durante 3 segundos. Luego se limpia solamente el tablero y comienza una nueva ronda. El marcador no se reinicia.

El botón "Reiniciar Juego" sirve para empezar completamente desde cero. Al presionarlo se limpia el tablero y también se ponen en 0 las victorias de X, las victorias de O y los empates.

  • No se puede ocupar una casilla que ya tenga un símbolo.
  • No se puede seguir jugando después de que termine la ronda.
  • X siempre comienza la ronda.
  • El marcador permanece entre rondas hasta utilizar "Reiniciar Juego".
